# LazyScript 19.1.0 – Assignment Studio foundation

## Included
- Assignment Studio profile panel for student name, enrollment number and course code.
- Persistent local profile preferences in the current browser.
- Configurable footer for handwritten-editor PDF exports: student name, enrollment number and sequential page number.
- Footer size and bottom offset controls; preview overlay and PDF overlay.
- Help drawer with a concise getting-started guide.
- Type-only import compatibility fixes for TypeScript `verbatimModuleSyntax` and parameter-property compatibility for `erasableSyntaxOnly`.
- Existing editor, handwriting rendering, math, image/table and `.lazy` project workflows retained.

## Not included in this build
- PDF assembly/merging of cover page + identity card + question paper + handwritten assignment. The PDF assembler and cover-page field overlay remain planned work and are not represented as completed.
- Footer injection into externally uploaded PDFs. This release adds the footer to pages generated by the handwriting editor only.
